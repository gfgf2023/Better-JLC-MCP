# 实现与验收报告

验证日期：2026-09-07。环境：Windows、Node.js 24.14.1、嘉立创EDA专业版 3.2.149、官方 Run API Gateway。源码版本 0.1.0。

## 结论

首版 MCP 已实现并完成真实原理图到 PCB 操作闭环。自动化回归 40/40 通过；真实测试板 9 个网络全部连通，PCB 原生 DRC 空列表，保存关闭重开后仍通过。全程未调用全网自动布线或自动差分布线。

总体验收标为 **部分通过**：原理图 API 仍返回一个无明细的警告分类，用户在界面未看到错误；三组各三次的模型对照尚未执行，地回流质量及制造审查未验收。不得据此宣称设计效果优于原版或可直接投产。

## 自动化回归

`npm run build`、`npm test`、真实 stdio MCP 协议测试通过。40 项覆盖：

- PCB/原理图 mm 与 mil 换算；旋转后的世界引脚坐标。
- 窗口/文档目标门禁、同窗口串行、跨进程窗口锁、操作去重、参数校验。
- 部分成功和传输失败的恢复读回；非成功设置 MCP isError。
- 只有短线不等于全网连通；异层交叉、缺过孔、第三个孤立焊盘、同层短路。
- 不同网络焊盘、已有铜线、旋转与圆角焊盘、禁布区、板边、无可行路径。
- 未知铜皮/特殊焊盘/缺失板框不能误报通过。
- 默认及间接调用入口拒绝自动布线与任意代码；实际 MCP 工具检索、完整 schema、提示与资源。
- 端口重叠反例对应的显式导线桩、实际 Value/供应商属性、布尔与汇总型 DRC。
- EDA 空特殊形状数组、组合焊盘 ID、铜线合并/分段的路径覆盖与缺段检查。
- 空白截图拒绝、额外短接引脚拒绝、对照记录公平性与完整性校验。

模拟与协议测试用于回归，不代替下述真实 EDA 验收。

## 实测限制

- 本机本地模式 createProject 未成功，因此使用用户明确授权的已有空工程。项目创建能力未通过实测。
- importChanges 可能需要界面确认。返回 true 不代表同步完成，工具检查实际对象并返回部分成功，不能盲目重放。
- 一次原理图引脚读回发生暂时错误，导线已实际创建。恢复后按网表跳过已完成连接，没有重复写入。
- EDA 合并重合铜线时会删除新返回的 ID；工具以实际连续覆盖验证路径，保留 ID 变化事实。无法把合并后的铜线视为可任意删除的原操作对象。
- 过孔尺寸有原生 mil 舍入；实测采用 0.6096/0.3048 mm。公开工具严格回读，不把请求尺寸当实际尺寸。
- 保存首轮重开会发生约 0.000001 mm 的坐标舍入。对比采用明确的 0.00001 数值容差，并保留结构、网络与层信息比较。
- 原理图属性字号行为与常用字号不同，已撤下未经标定的字号参数，采用 EDA 默认字体。
- 铜皮、region/部分禁布图元、特殊焊盘及复杂内层几何不完整支持；遇到时阻止路由或返回 unknown。
- Codex/Claude Code/OpenCode 提供配置示例；已测试标准 MCP stdio 客户端，未逐个客户端界面安装验收。
- [三组对照协议](../docs/EVALUATION.md)与记录校验器已提供，实际对照 `not_run`。
