# 已有 PCB 的编辑流程（0.2.0）

先 `eda_session` 核验目标，再 `pcb_get_edit_context` 获取编辑 revision、图元类型、ID、属性和可用 API。可以按 kinds/ids 筛选，未筛选部分仍参与 revision。编辑 revision 与 `pcb_get_state` 的布线 revision 不同，不能混用。

## 工具

| 工具 | 用途 |
| --- | --- |
| `pcb_get_edit_context` | 精确读取 pads、Fill、Pour、Poured、Line、Arc、Polyline、Region 的源属性 |
| `pcb_get_pads` / `pcb_resolve_pad_pair` | 按网络/位号查询或解析“位号＋引脚号”端点，不选择路径 |
| `pcb_create_pad` / `pcb_update_pad` | 创建独立焊盘、修改板上焊盘；不编辑封装库，未指定字段保持 |
| `pcb_create_copper` / `pcb_update_copper` | 明确区分 `fill` 固定铜形状与 `pour` 可重铺边框；修改多边形、网络或层 |
| `pcb_rebuild_pours` | 对明确 ID 调用官方 `rebuildCopperRegion()`，返回真实填充对象及 DRC |
| `pcb_update_outline_primitive` | 局部修改已有直线、圆弧、折线板框；读回真实 ID，之后检查全轮廓闭合 |
| `pcb_replace_outline` | 用一个模型指定的闭合轮廓替换明确列出的全部现有板框对象 |
| `pcb_delete_objects` | 删除明确 ID 的固定铜/覆铜边框/独立焊盘；拒绝组件焊盘和锁定图元 |
| `pcb_get_connectivity` | 查看含固定铜形状的连通分量、短路及未知几何 |

写操作使用 `target`、唯一 `operationId` 和最新编辑 `revision`。已锁定对象不隐式解锁。API 返回成功还要检查读回字段；静默拒绝/舍入不符合请求返回 partial。删除失败或通信异常保留实际变更记录和备份，不能重放。

官方板框接口可能更换图元编号但仍返回旧编号。工具只通过“旧对象已消失＋唯一新对象＋完整已观察属性相符”恢复真实 ID；歧义仍报告 partial。后续调用使用读回 ID。覆铜修改显式保留原优先级，防止名称修改改变重铺顺序。

## 单位与曲线

写入默认 mm，可显式选择 mil。`pcb_get_edit_context` 特意保留原始 `properties`，顶层明确标为 `unit: mil`，便于无损修改现有曲线；将这些源数组直接写回时必须指定 `unit: mil`。`pcb_get_state` 与 `pcb_get_pads` 返回 mm。Poured 的填充路径单独标为未标定单位。

多边形使用受校验的数据数组，不是任意代码：

```json
[0, 0, "L", 10, 0, "ARC", 90, 12, 2, "L", 12, 10, 0, 10]
```

`ARC/CARC` 后为角度、终点 X、终点 Y，角度不进行长度换算。`CIRCLE` 为圆心 X/Y、半径。`R` 为左上 X/Y、宽、高、旋转度数、圆角半径；PCB 的 Y 朝上，所以高向负 Y 延伸。曲线用真实圆弧参与几何运算，不将射频铜形状粗略折线化。暂不接收贝塞尔 C 命令。

创建固定铜/覆铜和替换板框使用一个简单闭合轮廓，拒绝自交；局部板框折线可为开放路径。现有复杂固定 Fill 的多个闭合轮廓按包含关系处理孔洞/孤岛；不把相同图元下的分离岛屿当成一整块导通铜。

## 对数周期天线等 RF 图形

先确认 fixed Fill 和 Pour 各自用途，读取全部板框段与原始圆弧。只修改用户指定的几何参数，保留馈电焊盘网络、钻孔、层和禁布约束。不要为了让连通检查通过而删除未知图元、把辐射结构转换成地铜或套用普通 MCU 布局。

编辑后读回参数、局部与全局截图、DRC；制造尺寸正确也不能推导驻波、增益、阻抗匹配或工作频带满足。射频性能需要独立电磁仿真/测量。

## 验证能力边界

- 固定实心 Fill 的直线/圆弧/圆形/矩形及孔洞可作为铜几何；只支持顶/底铜层。
- 支持 Line/Arc/Polyline 拼接的已有板框，支持明确 NO_WIRES 区域的走线禁布几何。
- 能创建/修改椭圆、长圆、矩形和正多边形焊盘；特殊形状或尚未可靠解释的非圆椭圆/正多边形仍可能无法完整验证。编辑支持与电气验证支持分别报告。
- 实测无孔焊盘修改后孔旋转可为 null，保存重开又恢复 0。这些无孔时不适用的字段明确列在证据中；有孔时不忽略。`hole:null` 删除已有钻孔的官方行为未通过验证，当前提前拒绝。2 mm 焊盘尺寸可能被舍入为 78.7 mil，读回不符返回 partial。
- 可编辑和重建 Pour，但不会把边框当作实际铜。Poured.path 的尺度、刷新与岛屿语义尚未标定，因此含 Pour 的完整路由/连通检查仍会返回 unknown。
- 多层 Fill 的机械含义、内层、复杂特殊焊盘和铜弧走线等仍存在未覆盖对象；不得把局部解析成功当作整板验收。
- 板框替换先创建并读回新对象再删除旧对象。发生部分失败时可能暂存两组板框；不自动覆盖整个文档回退。

真实独立测试页的结果和未通过项见 [验收报告](../reports/PCB-EDITING-VALIDATION.md)。`eda_create_test_pcb` 仅用于已授权的新测试页；本机创建成功但改名未成功，不能因 partial 再建一页。
